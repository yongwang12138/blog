# C++ 仅头文件库整理

这里记录一些实用的 C++ 仅头文件库，集成简单，适合快速上手。

## HTTP 服务

- **cpp-httplib**
  - 仓库地址: https://github.com/yhirose/cpp-httplib.git
  - 简介: 轻量级 HTTP/HTTPS 客户端与服务端库，API 简洁，适合快速搭建小型服务。

## TOML

- **toml++ (tomlplusplus)**
  - 仓库地址: https://github.com/marzer/tomlplusplus.git
  - 简介: 现代 C++ 的 TOML 解析与序列化库，类型支持完善，使用体验好。

## JSON

- **nlohmann/json**
  - 仓库地址: https://github.com/nlohmann/json.git
  - 简介: 非常流行的现代 C++ JSON 库，接口友好，支持序列化与反序列化。

## XML

- **pugixml**
  - 仓库地址: https://github.com/zeux/pugixml
  - 简介: 高性能 XML 解析库，接口直观，文档成熟。

## Plog 日志库

- **plog**
  - 仓库地址: https://github.com/SergiusTheBest/plog.git
  - 简介: 轻量、可扩展的日志库，支持多种输出目标与日志级别。
